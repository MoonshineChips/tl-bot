# TL Bot

The community bot of **TL Pro**, a Terraria launcher for Android ([terlauncher.com](https://terlauncher.com)).
It runs only on the TL Pro Discord server (and a private test server) and in the official TL Pro Telegram chat.

- **Levels and achievements** in Terraria style: materials from Dirt to Luminite, a game-style progress card,
  74 achievements, reputation for helpful answers.
- **Support tickets** in private threads and closed beta applications with a short form.
- **Bug report and idea forms**, language buttons for rules and FAQ (EN · RU · PT · ES · ZH).
- **Moderation helpers**: spam trap, staff-only cleanup, announcements mirrored to Telegram.
